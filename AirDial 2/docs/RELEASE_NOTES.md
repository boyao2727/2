AirDial 0.1.0 beta — macOS 13+, Apple Silicon and Intel universal app.

- Menu bar controls with automatic/manual modes.
- Simplified Chinese and US English, with persistent immediate language switching.
- Local Apple Vision gesture recognition; no photo/video storage, uploads, microphone, or Photos access.
- Full clockwise/counterclockwise turns change system volume by five percentage points.
- Side-palm swipes send Next/Previous; open-palm-to-fist sends Pause; thumbs-up sends Play.
- Wrist-only rotation is experimental; orientation uses 2D heuristics and requires real-camera validation.
- Media control uses a private send-only macOS bridge; player and OS compatibility vary.
